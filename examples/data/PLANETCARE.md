# PlanetCare: a generated dataset

PlanetCare is a **synthetic dataset generated by the author for teaching**. It describes no real product,
hospital, patient or support team. All names are fictional:
- hospital names such as "Hilltop Health";
- patient references `HN-0001` …;
- product modules such as "PC-Finance".

Any resemblance to real organisations is coincidental.

| File | Contents | Notebooks |
| :--- | :--- | :--- |
| `planetcare_tickets.json` | 183 support tickets for a fictional hospital EHR product, across 10 fictional hospitals. Fields: `ticket_id`, `summary`, `description`, `classification`, `hospital`, `status`, `resolution`, `priority`, `module`, `version` | 03, 06 |
| `planetcare_kb.json` | 3 knowledge-base articles | 03 |
| `planetcare_wiki/` | Team wiki pages: billing, laboratory and pharmacy, plus an index | 03 |

## Known quirks

The quirks are kept so that the notebooks' results reproduce, and some are useful for the data-cleaning steps of
notebook 03:
- 183 tickets carry only 181 distinct IDs, because `PC-00029` and `PC-00030` each appear twice.
- Version strings are inconsistent (`1.0` vs `v1.0`).
- Some tickets are in French.
